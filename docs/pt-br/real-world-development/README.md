Explore o GitHub Copilot em todo o ciclo de vida do desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é uma pessoa desenvolvedora recém-contratada pela Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com um tema voltado a desenvolvedores. O backlog da equipe já está registrado como issues do GitHub e pronto para você escolher. Ele inclui recursos como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de código.

## Escolher seu ambiente

O GitHub Copilot acompanha você onde quer que trabalhe. Escolha o ambiente que corresponde à maneira como quer desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado do Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente com agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra práticos.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne entre os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo de área de trabalho.

### [GitHub Copilot cloud agent][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, monitore o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
