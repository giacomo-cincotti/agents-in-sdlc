通过真实场景、完整应用和共享待办事项，在软件开发生命周期中探索 GitHub Copilot。你将以迭代方式规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为以开发者为主题的棋盘游戏提供众筹服务。团队的待办事项已作为 GitHub 议题创建，可供你领取。其中既有筛选和分页等功能任务，也有无障碍访问和编码规范等质量改进任务。

## 选择工作环境

无论在哪里工作，都可以使用 GitHub Copilot。选择最适合你构建方式的环境。每个研讨会都从自己的设置步骤开始，并采用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手，体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge，以及实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用画布，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
